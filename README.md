# Dashboard de Locações Imobiliárias - Power BI

## Sobre o projeto

Este projeto foi desenvolvido com foco em análise de dados e visualização de indicadores aplicados ao setor imobiliário.

O objetivo é estruturar dashboards operacionais utilizando dados fictícios de locação imobiliária, permitindo análises estratégicas e acompanhamento de métricas relevantes para o negócio.

---

## Objetivos do projeto

- Desenvolver dashboards no Power BI
- Criar indicadores operacionais
- Estruturar análises de locação imobiliária
- Aplicar conceitos de Business Intelligence
- Demonstrar raciocínio analítico com dados operacionais

---

## Indicadores analisados

- Total de imóveis alugados
- Taxa de aprovação cadastral
- Receita mensal de locações
- Índice de inadimplência
- Contratos ativos
- Tempo médio de locação
- Distribuição por região
